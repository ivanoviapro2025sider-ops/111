# dep-analyzer — Анализатор зависимостей метаданных 1С

Инструмент для анализа XML-выгрузок конфигураций 1С:Предприятие 8.3. Строит полный граф зависимостей между объектами метаданных, находит точки отладки в BSL-коде и выполняет аудит прав ролей.

## Возможности

### Анализ зависимостей (mode: deps)
- Рекурсивный обход графа зависимостей до заданной глубины
- Все типы связей: ссылки в реквизитах, движения документов, подписки на события, вызовы BSL, обращения в запросах
- Направление обхода: исходящие, входящие или все

### Отладка (mode: debug)
- Поиск процедур проведения документов
- Обработчики подписок на события
- Все BSL-процедуры и функции объекта с номерами строк
- Контекст точки остановки

### Аудит прав (mode: rights)
- Права всех ролей на указанный объект
- Поддержка RLS (ограничение на уровне записей)
- Шаблоны ограничений доступа
- Разделение разрешённых/запрещённых прав

### Полный анализ (mode: full)
- Комбинированный вывод всех трёх режимов

## Установка и запуск

### Требования
- Python 3.8+
- lxml (`pip install lxml`)

### Запуск

```bash
python3 scripts/dep-analyzer.py --config-path /path/to/config --mode deps --target Catalog.Номенклатура
```

### PowerShell (Windows/Linux/macOS)

```powershell
.\scripts\dep-analyzer.ps1 -ConfigPath "C:\Config" -Mode deps -Target "Catalog.Номенклатура"
```

PowerShell-обёртка автоматически находит Python и устанавливает lxml при необходимости.

## Форматы вывода

| Формат | Описание |
|--------|----------|
| `text` | Текстовый вывод для терминала |
| `json` | Структурированный JSON для интеграции |
| `md`   | Markdown-таблицы для документации |

## Типы рёбер графа

| Тип | Описание |
|-----|----------|
| `doc_to_register` | Документ → регистр (движения) |
| `doc_to_catalog` | Документ → справочник (реквизит) |
| `doc_to_document` | Документ → документ |
| `catalog_to_catalog` | Справочник → справочник |
| `register_to_catalog` | Регистр → справочник (измерение/ресурс) |
| `subscription_to_object` | Подписка → объект-источник |
| `subscription_to_module` | Подписка → общий модуль-обработчик |
| `bsl_call` | Вызов модуля из BSL-кода |
| `bsl_query_ref` | Ссылка на объект в тексте запроса |
| `based_on` | Ввод на основании |
| `owner` | Владелец справочника |

## Пагинация

Для больших конфигураций используйте `--limit` и `--offset`:

```bash
# Первые 50 записей
python3 dep-analyzer.py --config-path ./cf --target Catalog.X --limit 50

# Следующие 50
python3 dep-analyzer.py --config-path ./cf --target Catalog.X --limit 50 --offset 50
```

## Поддерживаемые типы объектов

Справочники, документы, регистры сведений, регистры накопления, регистры бухгалтерии, регистры расчёта, перечисления, планы видов характеристик, планы счетов, планы видов расчёта, бизнес-процессы, задачи, планы обмена, обработки, отчёты, общие модули, подписки на события, роли, константы, журналы документов, регламентные задания, определяемые типы, HTTP-сервисы, веб-сервисы.
