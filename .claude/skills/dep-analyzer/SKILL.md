# dep-analyzer

Анализатор зависимостей, отладки и прав метаданных конфигураций 1С:Предприятие.

## Описание

Skill анализирует XML-выгрузку конфигурации 1С и предоставляет:
- **deps** — полный граф зависимостей между объектами метаданных
- **debug** — точки остановки для отладки (процедуры проведения, подписки, модули)
- **rights** — аудит прав ролей на объекты (включая RLS)
- **full** — комбинированный вывод всех режимов

## Вызов

```
dep-analyzer --config-path <путь> --mode <режим> --target <объект> [опции]
```

### Параметры

| Параметр | Обязательный | По умолчанию | Описание |
|----------|-------------|-------------|----------|
| `--config-path` | Да | — | Путь к корню XML-выгрузки конфигурации |
| `--mode` | Нет | `deps` | Режим: `deps`, `debug`, `rights`, `full` |
| `--target` | Нет | — | Объект: `Catalog.Номенклатура` или `Номенклатура` |
| `--depth` | Нет | `3` | Глубина обхода графа зависимостей |
| `--format` | Нет | `text` | Формат: `text`, `json`, `md` |
| `--limit` | Нет | `150` | Макс. записей в выводе |
| `--offset` | Нет | `0` | Смещение для пагинации |
| `--out-file` | Нет | — | Файл для вывода (по умолчанию stdout) |

### Примеры

```bash
# Зависимости справочника
dep-analyzer --config-path ./src/cf --mode deps --target Catalog.Номенклатура

# Точки отладки документа
dep-analyzer --config-path ./src/cf --mode debug --target Document.РеализацияТоваровУслуг

# Аудит прав в JSON
dep-analyzer --config-path ./src/cf --mode rights --target Catalog.Номенклатура --format json

# Полный анализ с глубиной 5
dep-analyzer --config-path ./src/cf --mode full --target Catalog.Номенклатура --depth 5
```

## Зависимости

- Python 3.8+
- lxml

## Запуск через PowerShell

```powershell
.\dep-analyzer.ps1 -ConfigPath ".\src\cf" -Mode deps -Target "Catalog.Номенклатура"
```

## Поддерживаемые типы объектов

Справочники, документы, регистры (сведений, накопления, бухгалтерии, расчёта), перечисления, планы видов характеристик, планы счетов, планы видов расчёта, бизнес-процессы, задачи, планы обмена, обработки, отчёты, общие модули, подписки на события, роли, константы, журналы документов, регламентные задания, определяемые типы, HTTP-сервисы, веб-сервисы.
