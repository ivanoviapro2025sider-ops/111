# dep-analyzer

**Анализатор зависимостей, отладки и прав метаданных 1С**

## Описание

Skill для анализа конфигураций 1С:Предприятие, выгруженных в XML. Строит полный граф зависимостей метаданных, определяет реальные точки остановки по BSL-коду, проводит аудит прав (включая RLS).

## Возможности

- **deps** — Граф зависимостей объекта с рекурсивным обходом по глубине
- **debug** — Точки остановки для отладки: процедуры, обработчики подписок, проведение
- **rights** — Аудит прав ролей на объект: Read/Update/View/... + условия RLS
- **full** — Полный анализ: deps + debug + rights
- **list** — Список объектов конфигурации с фильтрацией

## Запуск

### Python
```bash
python3 scripts/dep-analyzer.py \
  --config-path /path/to/config \
  --mode deps \
  --target "Document.РеализацияТоваровУслуг" \
  --depth 3 \
  --out-format text
```

### PowerShell
```powershell
./scripts/dep-analyzer.ps1 `
  -ConfigPath /path/to/config `
  -Mode deps `
  -Target "Document.РеализацияТоваровУслуг" `
  -Depth 3 `
  -OutFormat text
```

## Параметры

| Параметр | Обязательный | По умолчанию | Описание |
|----------|:---:|:---:|---|
| `--config-path` / `-ConfigPath` | Да | — | Путь к корню XML-выгрузки |
| `--mode` / `-Mode` | Нет | `deps` | Режим: deps/debug/rights/full/list |
| `--target` / `-Target` | Да* | — | Целевой объект или фильтр |
| `--depth` / `-Depth` | Нет | `3` | Глубина обхода графа |
| `--out-format` / `-OutFormat` | Нет | `text` | Формат: text/json/md |
| `--limit` / `-Limit` | Нет | `150` | Лимит записей |
| `--offset` / `-Offset` | Нет | `0` | Смещение пагинации |
| `--out-file` / `-OutFile` | Нет | stdout | Файл для записи |

\* Обязателен для режимов deps/debug/rights/full

## Форматы Target

- `Document.РеализацияТоваровУслуг` — полный ключ
- `Документ.РеализацияТоваровУслуг` — русский тип
- `РеализацияТоваровУслуг` — поиск по имени

## Поддерживаемые типы метаданных

Справочники, Документы, Регистры (сведений/накопления/бухгалтерии/расчёта), Перечисления, ПВХ, Планы счетов, Планы видов расчёта, Бизнес-процессы, Задачи, Планы обмена, Отчёты, Обработки, Общие модули, Подписки на события, Роли, Константы, Журналы документов.

## Зависимости

- Python 3.8+
- lxml (устанавливается автоматически при запуске через PowerShell)
