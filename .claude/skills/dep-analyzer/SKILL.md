# dep-analyzer

Анализатор зависимостей, отладки и прав метаданных 1С.

## Описание

Skill для анализа выгруженной конфигурации 1С:Предприятие. Строит полный граф зависимостей между объектами метаданных, находит точки отладки по BSL-коду, проводит аудит прав (включая RLS).

## Возможности

- **deps** — граф зависимостей: связи документов, справочников, регистров, подписок, BSL-вызовов
- **debug** — точки остановки: процедуры проведения, подписки на события, экспортные модули
- **rights** — аудит прав: чтение/запись/просмотр по ролям, RLS-условия, шаблоны ограничений
- **full** — полный анализ: все три режима в одном выводе

## Параметры

| Параметр | Обязательный | По умолчанию | Описание |
|----------|-------------|-------------|----------|
| `ConfigPath` | Да | — | Путь к каталогу выгрузки конфигурации 1С |
| `Mode` | Нет | `deps` | Режим: `deps`, `debug`, `rights`, `full` |
| `Target` | Нет | `""` | Целевой объект: `Document.РеализацияТоваровУслуг`, `Catalog.*`, `*.Номенклатура` |
| `Depth` | Нет | `3` | Глубина обхода графа зависимостей |
| `OutFormat` | Нет | `text` | Формат вывода: `text`, `json`, `md` |
| `Limit` | Нет | `150` | Максимальное количество записей |
| `Offset` | Нет | `0` | Смещение для пагинации |
| `OutFile` | Нет | `""` | Путь к файлу результата (пусто = stdout) |

## Использование

### PowerShell
```powershell
.\dep-analyzer.ps1 -ConfigPath "C:\MyConfig" -Mode deps -Target "Document.РеализацияТоваровУслуг"
.\dep-analyzer.ps1 -ConfigPath "./config" -Mode full -Target "Catalog.*" -OutFormat json
```

### Python
```bash
python3 dep-analyzer.py --config-path ./MyConfig --mode deps --target "Document.РеализацияТоваровУслуг"
python3 dep-analyzer.py --config-path ./MyConfig --mode rights --target "Catalog.Номенклатура" --format md
```

## Зависимости

- Python 3.8+
- lxml (автоустановка через PowerShell-обёртку)

## Поддерживаемые типы объектов

Справочники, Документы, Регистры (сведений, накопления, бухгалтерии, расчёта), Перечисления, ПВХ, Планы счетов, ПВР, Бизнес-процессы, Задачи, Планы обмена, Отчёты, Обработки, Общие модули, Подписки на события, Роли, Константы, Журналы документов.

## Типы связей в графе

- Движения документов по регистрам
- Ссылки через реквизиты (включая табличные части)
- Владельцы и иерархия справочников
- Подписки на события → объекты и обработчики
- Вызовы общих модулей из BSL
- Обращения к метаданным в BSL (Справочники.Номенклатура)
- Ссылки в текстах запросов 1С
- Ввод на основании
