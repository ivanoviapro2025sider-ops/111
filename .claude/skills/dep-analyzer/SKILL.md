# dep-analyzer — Анализатор зависимостей метаданных 1С

## Описание

Skill для анализа конфигураций 1С:Предприятие, выгруженных в XML. Строит полный граф зависимостей объектов метаданных, определяет точки отладки по BSL-коду и выполняет аудит прав (включая RLS).

## Возможности

- **Граф зависимостей** — связи между документами, справочниками, регистрами, подписками, общими модулями
- **Анализ BSL-кода** — извлечение процедур, вызовов модулей, обращений к метаданным, ссылок в запросах
- **Аудит прав** — парсинг ролей, Rights.xml, RLS-ограничений и шаблонов
- **Точки отладки** — определение процедур для установки breakpoints с контекстом
- **Рекурсивный обход** — параметр Depth для управления глубиной анализа
- **Форматы вывода** — text, json, md

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `ConfigPath` | string | *(обязательный)* | Путь к каталогу конфигурации 1С |
| `Mode` | string | `deps` | Режим: `deps`, `debug`, `rights`, `full` |
| `Target` | string | `""` | Целевой объект (например, `Document.РеализацияТоваровУслуг`) |
| `Depth` | int | `3` | Глубина обхода графа зависимостей |
| `OutFormat` | string | `text` | Формат вывода: `text`, `json`, `md` |
| `Limit` | int | `150` | Максимум записей в выводе |
| `Offset` | int | `0` | Смещение для пагинации |
| `OutFile` | string | `""` | Путь к файлу для записи (stdout если пусто) |

## Режимы работы

### deps — Граф зависимостей
Показывает связи объекта: какие справочники использует документ, какие регистры движет, вызовы общих модулей, ссылки в запросах.

### debug — Точки отладки
Список процедур BSL-кода с номерами строк и контекстом (проведение, запись, создание формы и т.д.).

### rights — Аудит прав
Права ролей на объект и связанные объекты, включая RLS-ограничения и шаблоны.

### full — Полный анализ
Объединение deps + debug + rights в одном выводе.

## Примеры вызова

```bash
# Зависимости документа
python scripts/dep-analyzer.py --config-path ./MyConfig --mode deps --target "Document.РеализацияТоваровУслуг"

# Точки отладки в JSON
python scripts/dep-analyzer.py --config-path ./MyConfig --mode debug --target "Document.РеализацияТоваровУслуг" --out-format json

# Аудит прав в Markdown
python scripts/dep-analyzer.py --config-path ./MyConfig --mode rights --out-format md

# Полный анализ с записью в файл
python scripts/dep-analyzer.py --config-path ./MyConfig --mode full --target "Catalog.Номенклатура" --out-format md --out-file report.md
```

```powershell
# PowerShell-обёртка
.\scripts\dep-analyzer.ps1 -ConfigPath "C:\MyConfig" -Mode deps -Target "Document.РеализацияТоваровУслуг"
```

## Зависимости

- Python 3.8+
- lxml (устанавливается автоматически через PowerShell-обёртку)

## Поддерживаемые типы объектов

Справочники, документы, регистры (сведений, накопления, бухгалтерии, расчёта), перечисления, планы видов характеристик, планы счетов, планы видов расчёта, бизнес-процессы, задачи, планы обмена, отчёты, обработки, общие модули, подписки на события, роли, константы, журналы документов, регламентные задания, определяемые типы, HTTP-сервисы, Web-сервисы.
