# Лендинг для продажи новой конфигурации 1С

Статический сайт для быстрого продвижения пилотного проекта новой конфигурации 1С.

## Что внутри

- Сильный оффер и CTA в первом экране
- Блоки возможностей и выгод
- Пошаговый сценарий пилота
- Ценообразование и FAQ
- Форма сбора лидов с базовой валидацией

## Структура

- `index.html` — разметка лендинга
- `styles.css` — адаптивные стили
- `script.js` — клиентская логика формы

## Локальный запуск

```bash
python3 -m http.server 8080
```

После запуска откройте:

`http://localhost:8080`
